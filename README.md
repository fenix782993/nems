# NEMAZING RP

Telegram RP bot: subscription check, applications, organizations, personnel, reports, criteria, Excel export, organization chat tracking and FastAPI health endpoint.

## Run
1. Copy `.env.example` to `.env`.
2. Set `BOT_TOKEN` and `OWNER_ID`.
3. `pip install -r requirements.txt`
4. `python -m app.main`

## Render
Build: `pip install -r requirements.txt`
Start: `python -m app.main`
Health: `/health`

Bot must be admin in @nemazing and organization chats.
